# Solar System Now (リアルタイム太陽系クロノメーター)

ケプラーの法則に基づいた正確な惑星位置を計算し、3Dで表示するリアルタイム太陽系シミュレーターです。過去や未来へのタイムトラベル機能も備えています。

![Hero Image](src/assets/hero.png)

## 🌟 主な機能

- **高精度な軌道計算**: NASA JPLの近似データ（Epoch J2000）を使用し、惑星の現在位置を算出。
- **タイムトラベル**: シミュレーション速度を自由に変更（数日/秒）し、惑星の動きを観察可能。
- **インタラクティブ操作**: 3D空間での自由なカメラ操作（回転・ズーム）と、各惑星へのフォーカス機能。
- **詳細情報パネル**: 選択した惑星の軌道要素（離心率、軌道傾斜角、太陽からの距離など）を表示。
- **衛星のシミュレーション**: 地球の月や木星のガリレオ衛星など、主要な衛星の公転も再現。

## 🚀 技術スタック

- **Frontend**: React 19 + TypeScript

- **Physics/Math**: Keplerian Orbit Mechanics
- **Styling**: Tailwind CSS v4
- **State Management**: Zustand

## 🌌 シミュレーションの詳細

このアプリでは、ケプラー方程式（$M = E - e \sin E$）をニュートン法で解くことにより、任意の時刻における惑星の離心近点角（Eccentric Anomaly）を求め、三次元座標を算出しています。

- **1 AU (天文単位)**: シミュレーション内では 10 ユニットとしてスケーリングされています。
- **時間軸**: 2000年1月1日 12:00 (J2000.0) を基準エポックとして計算しています。
