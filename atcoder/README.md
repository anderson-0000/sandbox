# AtCoder Solutions

このディレクトリには、競技プログラミングサイトAtCoderの問題に対する解答コードが格納されています。

## 概要

各ファイルは、AtCoderの特定の問題に対するPythonでの解答です。
ファイル名には、問題のカテゴリ（A, B, Cなど）と問題名、必要に応じてバージョン情報が含まれています。

## 構成例

- `A - Product.py`: AtCoder Beginner Contest (ABC) のA問題「Product」の解答。
- `B - Some Sums.py`: AtCoder Beginner Contest (ABC) のB問題「Some Sums」の解答。

これらのコードは、競技プログラミングの練習や学習のために利用されます。
