# FloorPlan Designer (間取り作成Webアプリケーション)

新居建築に向けた、家屋の広さ・配置のイメージを具体化するためのシミュレーションツールです。

## 主な機能

- **モジュール切替**: 「尺モジュール（910mm）」と「メーターモジュール（1000mm）」をワンタッチで切り替え可能。
- **オブジェクト配置**: 部屋、ガレージ、車両、設備（プロジェクター）をキャンバス上に配置・移動・回転。
- **リアルタイム面積計算**: 延床面積と建築面積を「㎡」および「坪」で自動計算。
- **特殊シミュレーション**: 
  - 車両のドア開閉スペース可視化。
  - ホームシアターの100インチ投影距離シミュレーション。
- **ローカル保存**: ブラウザ上での状態保持（※実装予定：JSONエクスポート/インポート）。

## 起動方法 (How to Run)

1. リポジトリをクローンまたはダウンロードします。
2. プロジェクトディレクトリに移動します。
   ```bash
   cd floor-plan-designer
   ```
3. 依存関係をインストールします。
   ```bash
   npm install
   ```
4. 開発サーバーを起動します。
   ```bash
   npm run dev
   ```
5. ブラウザで `http://localhost:5173` を開きます。
