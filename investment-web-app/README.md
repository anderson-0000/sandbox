# 投資信託シミュレーター (Web版)

このアプリケーションは、Python (Flask) をバックエンドとし、HTML, CSS, JavaScript (Chart.js) をフロントエンドとして使用したWebツールです。モンテカルロ・シミュレーションを用いて2つの異なる投資信託の組み合わせによる将来の資産価値を予測し、結果をブラウザ上でグラフと表で表示します。

## 機能

-   `defaults.yaml` ファイルからデフォルト値を読み込み、フォームに自動入力。
-   直感的なWebフォームによるパラメーター入力。
-   2つの異なる投資信託のパラメーターに対応。
-   Pythonバックエンドでのモンテカルロ・シミュレーションによる将来の資産価値予測。
-   シミュレーション結果をインタラクティブなグラフ（Chart.js）と詳細な表で表示。
-   **グラフをPNG画像としてダウンロード可能。**

## 技術スタック

-   **バックエンド**: Python (Flask, PyYAML)
-   **フロントエンド**: HTML, CSS, JavaScript (Chart.js)

## セットアップと実行方法

### 1. Python環境の準備

#### 1.1. 仮想環境のセットアップとライブラリのインストール

プロジェクトディレクトリ (`investment-web-app`) に移動し、以下の手順で仮想環境をセットアップし、必要なライブラリをインストールします。これは、システムPythonとプロジェクトの依存関係の衝突を防ぐための推奨される方法です。

1.  **プロジェクトディレクトリへ移動:**
    ```bash
    cd investment-web-app
    ```
2.  **仮想環境の作成:**
    ```bash
    python3 -m venv venv
    ```
3.  **仮想環境のアクティベート:**
    ```bash
    source venv/bin/activate
    ```
    (このコマンドを実行すると、ターミナルのプロンプトの先頭に `(venv)` のような表示が追加されます。)
4.  **必要なライブラリのインストール:**
    ```bash
    pip install Flask Flask-Cors PyYAML
    ```
    (macOSで `externally-managed-environment` エラーが発生した場合は、この仮想環境内で `pip install` を再試行してください。)

### 2. アプリケーションの実行

**仮想環境がアクティベートされていることを確認し（プロンプトの先頭に `(venv)` があることを確認）、** 以下のコマンドをターミナルで実行して、Flaskサーバーを起動します。

```bash
python app.py
```

サーバーが起動すると、通常 `http://127.0.0.1:5000/` または `http://localhost:5000/` でアプリケーションにアクセスできます。

### 3. アプリケーションの使用

ブラウザでアプリケーションを開き、2つの投資信託それぞれについて必要な情報を入力してください。「シミュレーション実行」ボタンをクリックすると、モンテカルロ・シミュレーションの結果がグラフと表で表示されます。

### 4. グラフのダウンロード

シミュレーション結果のグラフが表示された後、グラフの下に表示される「グラフをダウンロード」ボタンをクリックすると、表示されているグラフがPNG画像としてダウンロードされます。
