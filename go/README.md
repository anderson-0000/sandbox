# Go Projects

このディレクトリには、Go 言語で書かれた各種プロジェクトやコードスニペットが格納されています。

## 概要

- `calculate_area/`: 面積計算に関するGoプログラム
- `int64time/`: int64型の時間操作に関するGoプログラム
- `metric_current_time/`: 現在時刻のメトリック取得に関するGoプログラム
- `metric_current_time2/`: 現在時刻のメトリック取得に関する別のGoプログラム
- `simple-chat/`: シンプルなチャットアプリケーションのGoプログラム
- `sort_version/`: バージョン文字列のソートに関するGoプログラム
- `test_method/`: メソッドのテストに関するGoプログラム

各サブディレクトリには、それぞれ独立したGoプロジェクトや機能が実装されています。
