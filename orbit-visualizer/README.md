# Orbit Visualizer

地球から月までの空間にある人工物（衛星、ISS、デブリ、スターリンクなど）と天然物（月）を1:1のリアルな縮尺で3D視覚化するアプリケーションです。

## 特徴
- **リアルなスケール**: 地球（半径6,371km）から月（距離384,400km）までの広大な空間を1:1の比率で表現。
- **ライブ衛星データ**: CelesTrakから取得した最新のTLE（2行軌道要素形式）データを使用し、`satellite.js`で現在の位置をリアルタイムに計算。
- **多量のオブジェクト描画**: Three.jsの`InstancedMesh`を使用し、数千個の衛星やデブリを効率的に表示。
- **色分け表示**:
  - 緑色: アクティブな人工衛星
  - 赤色: デブリ（宇宙ゴミ）
  - シアン: スターリンク衛星群
  - 黄色/白: 気象衛星やその他の衛星

## 起動方法 (How to Run)

### 開発用 (Development)
1. 依存関係のインストール:
   ```bash
   npm install
   ```
2. 開発サーバーの起動:
   ```bash
   npm run dev
   ```
   起動後、ブラウザで `http://localhost:5173` にアクセスしてください。

### ビルド用 (Build)
1. アプリケーションのビルド:
   ```bash
   npm run build
   ```
   `dist` ディレクトリに静的ファイルが生成されます。

## 技術スタック
- React + TypeScript
- Three.js (@react-three/fiber, @react-three/drei)
- satellite.js (軌道計算)
- Vite (ビルドツール)

---

### ローカル・データ・キャッシュ
- **Vite サーバー・ミドルウェア**: `vite.config.ts` に実装されたカスタム・プロキシにより、Celestrak から取得した TLE データを `cache/` ディレクトリに保存します。
- **2時間のキャッシュ有効期限**: 一度取得したデータは2時間保持され、不要な外部 API 呼び出しを抑制し、データ提供元への負荷を軽減します。
- **オフライン/API制限への耐性**: 外部サイトからアクセス制限（403 Forbidden）を受けている場合でも、最後に取得した有効なキャッシュを自動的に利用して表示を維持します。

### React-Three-Fiber (R3F) のコンテキスト制約
- **最重要:** `useThree`, `useFrame` などの R3F フックは、必ず `<Canvas>` コンポーネントの**内側**にあるコンポーネントでしか呼び出せません。
- 左下の UI パネル（2D 領域）などでカメラの高度データを使いたい場合は、`OrbitScene` 内に `CameraTracker` という中継用コンポーネントを配置し、`App` コンポーネントの状態（State）を更新して橋渡しする設計にしています。

### インタラクションと操作
- 衛星の選択には `onPointerDown` を使用し、ドラッグ操作（OrbitControls）との競合を避けています。
- 衛星の当たり判定を確実にするため、`SatelliteCloud` のジオメトリには手動で巨大な `boundingSphere` を設定し、レイキャスター（クリック判定）が無視されないようにしています。
