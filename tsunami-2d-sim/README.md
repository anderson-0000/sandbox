# 2D 津波断面シミュレーター (Tsunami 2D Simulator)

このアプリは、マグニチュード、震源の水深、および陸地からの距離を入力として、津波が海岸に近づくにつれてどのように変化するかを断面図で視覚化します。

## 主な機能
- **マグニチュード (Mw) 指定:** 地震の規模に応じた初期波高の推定。
- **グリーンの法則:** 水深が浅くなるにつれて波が高くなる物理現象をシミュレート。
- **断面図の表示:** 海底地形と海面（津波）を SVG で描画。

## 物理モデル
- 初期波高 $H_0$: $\log_{10}(H_0) = 0.5 M_w - 3.3$
- 波高変化: $H = H_0 \cdot (D_{source} / D)^{1/4}$ (グリーンの法則)

## 起動方法 (How to Run)

```bash
# ディレクトリに移動
cd sandbox/tsunami-2d-sim

# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで表示された URL（通常は http://localhost:5173）にアクセスしてください。
